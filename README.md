# RuntimeRogue

JavaScript を書いて敵と戦う、デッキ構築ローグライク（開発中）。

> ⚠️ **開発途中のプロジェクトです。**  
> 動作確認が不十分なため、バグが含まれている可能性があります。

---

## 起動方法

**Node.js が必要です**（配布zip版・開発版とも共通）。

### 配布されたzipを受け取った場合

1. zipを展開する
2. 中に入っている `ゲーム起動.bat` をダブルクリックする
3. 数秒待つと、自動的にブラウザが開いてプレイできます

（`.bat`は内部でローカルサーバーを起動し、ブラウザを`http://localhost:3000`宛てに開きます。プレイを終えたら、開いたコンソールのウィンドウを閉じるとサーバーが停止します）

### ソースコードから開発・実行する場合

初回のみ:
```
npm install
```

起動:
```
npm run dev
```

起動後、ブラウザで `http://localhost:5173` を開いてください。

---

## 遊び方

1. キャラクターを選択してバトル開始
2. ターン開始時に手札（カード）が配られる
3. エディタに JavaScript を書いて **RUN** ボタンを押す
4. カード関数（`attack()` など）を呼び出した分だけ効果が発動
5. 敵を倒したら報酬カードを選んでデッキを強化

---

## データの保存について

エディタに入力したコード（Main / Library / Daemon）やエディタプリセットは、**ブラウザのローカルストレージ**に保存されます。そのため、別のブラウザ・別の端末・シークレット（プライベート）ウィンドウなどでは引き継がれません。
