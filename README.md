# RuntimeRogue

JavaScript を書いて敵と戦う、デッキ構築ローグライク（開発中）。

> ⚠️ **開発途中のプロジェクトです。**  
> 動作確認が不十分なため、バグが含まれている可能性があります。

---

## 起動方法

### 初回
```
npm install
npm run dev
```

### 2回目以降
```
npm run dev
```

起動後、ブラウザで `http://localhost:5173` を開いてください。

Node.js v18 以上が必要です。

---

## 遊び方

1. キャラクターを選択してバトル開始
2. ターン開始時に手札（カード）が配られる
3. エディタに JavaScript を書いて **RUN** ボタンを押す
4. カード関数（`attack()` など）を呼び出した分だけ効果が発動
5. 敵を倒したら報酬カードを選んでデッキを強化

---

## エディタの種類

### メインエディタ（📝）
- RUN ボタンがある通常のエディタ
- ここに書いたコードが実行される

### ライブラリエディタ（📚）
- RUN ボタンがない補助エディタ
- 関数などを定義しておける場所
- メインエディタの RUN 時に、ライブラリのコードが先頭に自動的に結合されて実行される
- 複数のメインエディタで共通のヘルパー関数を使いたいときに便利

## アンロック関数

一部の関数は初期状態では使用できません。ゲーム内通貨で購入することでアンロックされます。

| 関数 | 内容 |
|------|------|
| `myDeck()` | デッキ全カードの配列を返す |
| `myHand()` | 現在の手札を返す |
| `myDrawPile()` | 山札を返す |
| `myDiscard()` | 捨て札を返す |
| `endTurn()` | コードからターンを終了する |
| `function` キーワード | 関数定義を使えるようにする |

アロー関数（`=>`）は最初から使用できます。
